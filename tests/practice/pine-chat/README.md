# 松果聊天

这是一个微信风格的本地合成演练工程。Vue 3 / 严格 TypeScript 做会话、通讯录和群管理；Java 21 做聊天规则与 HTTP 服务。四个演示身份共用同一份内存状态，可在页面左侧切换，也可用两个浏览器标签从发送方和接收方观察。无真实账户、数据或外部服务，重启恢复初始状态。

## 运行

需要 JDK 21、Node.js 22 和 npm。从此目录执行：

```sh
./run.sh
```

打开 <http://127.0.0.1:8787/>。用 `./run.sh 8790` 更换端口，或用 `./run.sh --build-only` 只构建。Vue 构建和 Java 编译是应用自身的启动步骤，不运行 Normalizer 回归。

## 体验路线

| 从哪里开始 | 操作与可观察结果 |
| --- | --- |
| 林澄的会话 | 界面先显示群内未读提及；点「提到我」再打开群聊，消息仍可见，未读标记清空。置顶会改变排序；免打扰消息不计入顶部总数，提及仍单独显示。 |
| 林澄的通讯录 | 何溪有待处理申请。接受立即打开私聊；拒绝保留陌生人关系。发送消息后切换何溪，能看到对方视角。拉黑后双方都不能继续发送，旧记录仍在；解除后恢复发送。 |
| 「松果创作组」 | 林澄打开群设置后可以设置仅管理员发言。切到普通成员许芒，输入框被禁用；由林澄提升许芒后再切回，许芒可以发送并提及其他成员。群主可邀请好友、移出成员，普通成员可以退出。新成员查看群历史不会增加未读计数。群内角色与私聊拉黑是独立规则。 |
| 撤回 | 本人新消息可在两分钟内撤回；两端看到占位提示，撤回内容不再可搜索。程序拒绝越权撤回、重复撤回和超时撤回。初始群公告属于林澄，已经超过时限。 |
| 搜索和输入 | 搜索覆盖会话名称与未撤回正文；筛选可只看未读或提及。空白输入、超过 300 个字符、权限受限和提交中均不可发送。Enter 发送，Shift+Enter 换行。 |

## 源码阅读入口

- [App.vue](frontend/src/App.vue)：身份切换、开会话及已读上报、申请决策、发送与撤回、群权限与不同界面状态。
- [model.ts](frontend/src/model.ts)：消息预览、未读与提及徽标、会话搜索与排序。
- [ChatServer.java](backend/src/practice/chat/ChatServer.java)：静态文件、请求解码、HTTP 入口与结构化失败。
- [ChatService.java](backend/src/practice/chat/ChatService.java)：会话与好友状态、权限、消息和用户间的观察差异。撤回窗口使用注入的时钟。

身份选择只是演练手段，不是认证；应用只绑定本机回环地址，不用于部署。刷新采用轮询，不承诺实时推送。
