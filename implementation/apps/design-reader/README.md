# 设计区阅览器

在 macOS 的 Finder 双击设计区的 [open.command](../../../design/open.command)，或从仓库根目录运行：

```sh
./design/open.command
```

脚本会打开本地阅览器。默认端口为 4176；若被其他程序占用，系统会自动分配空闲端口，终端会打印实际地址。重新启动会关闭同一份仓库的旧阅览器，其他程序和其他检出的阅览器不受影响。升级前启动的旧阅览器只有在系统能确认进程归属时才会被关闭。首次运行需要 Node.js 24 或更高版本和 npm，启动脚本会安装锁定的依赖。服务只监听本机。保留启动窗口，刷新即可读取最新的设计与测试。

左侧目录按“基础主题／联合主题 → 具体主题 → 种子案例”折叠展示。展开主题后可打开主题导读和案例；搜索会自动展开匹配的主题。

在种子页点击“关联测试”，按入口选择原例或变体，即可查看每个用例的完整预处理后输入及预期 PERS。预期拒绝的用例显示 CLI 应报告的诊断。可以收藏单条用例，也可以在目录中按变体名搜索。种子清单列出每个种子的测试数或“待派生”状态。

需要离线阅读时，可在安装过依赖后导出一个独立的 HTML 文件：

```sh
node implementation/apps/design-reader/reader.mjs --export "$HOME/Downloads/normalizer-design.html"
```

离线文件包含导出时的种子、关联测试详情和参考页，重新导出即可更新。
