# 行为语义与归约正确性

本文定义内核的语义保持义务；具体输入格式见[外部操作与完成](normalized-behavior.md)，最终输出见[最终 PERS 合同](kernel/final-pers.md)。模型不是完整 Java 或 JavaScript 的自动等价判定器，也不是机器检查证明。

## 统一状态与完成方式

一次执行的状态包含对象身份到字段值的堆 H、外部世界 W、已经发生的有序调用轨迹 τ 和外部响应消费位置。结果是完成方式及更新后的状态；完成方式包括正常继续、Continue、Break、Return(value)、Throw(class,payload)。

顺序组合只在前一步正常继续时执行后一步。Return/Throw 保留此前状态和轨迹；Break/Continue 由所属遍历消费；函数 scope 只消费自己的 Return。异常不自动回滚对象写入和外部调用。

对于非空引用，字段读写满足：

```text
read(write(H,r,f,v),q,g)
  = CASE WHEN r=q AND f=g THEN v ELSE read(H,q,g) END
```

未知别名必须保留身份条件；不同变量名不证明不同对象。读取的标量是读取时的快照，不能因后续写入改变。外部调用先按当前状态计算参数，再记录调用并绑定响应；抛异常的响应仍对应一次已发生调用。调用身份区分静态位置、动态迭代路径和实际序号。

有限遍历对空序列保持当前状态；每步正常继续或 Continue 时处理下一项，Break 时结束当前遍历，Return/Throw 时携带当前状态向外传播。未知长度保留有完整定义的纯递推；不能用固定次数展开替代一般有限输入，也不能强行将任意 while 映射为有限遍历。

## 两个独立的正确性义务

1. 原源码到规范源码及扩展定义：相同输入、初始状态、外部世界和观察范围下，转换前后行为一致。
2. 闭合统一 IR 到最终 PERS：归约及化简保留这些可观察关系。

观察包含返回或异常类型及载荷、出口可达状态、必要调用轨迹及外部世界变化。具体范围必须声明，例如异常消息或堆栈不在范围内时不能暗示已经保留。

第一项依赖源码证据与独立对照，不能从内核正确推定。第二项依赖语义规则和内核回归，不能从 AI 声称等价推定。有限样本对照是证据，不是普遍等价证明。来源指纹只证明材料身份。

## 规则的论证方法

表达式替换保持同一状态和绑定下的值；状态转发使用读写等式并保留别名条件；顺序和分支按子结构归纳；有限遍历按序列长度归纳；外部调用依赖相同前缀、参数和端口合同。每项规则必须明确类型、空值、异常、数值位宽及定义域前提。

内部行为 IR 是语义计算工具。最终产物是值表达式、纯共享或纯递推定义和结构化边界记录，不能直接将执行步骤改名塞进 PERS。精确表示、可靠化简、得到短小闭式公式是不同要求；不能保证任意程序都产生无递推或最短的表达式。
