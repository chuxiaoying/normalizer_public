# 有限索引的入口状态观察

索引化 E 把已有入口状态观察绑定到有限序列位置。它扩展最终 PERS 的表达结构。E 仍表示同一入口堆的字段值，S 调用族仍按实际调用实例取得独立的完成观察。这里规定测试验收的目标形式，生产状态归约尚未接通该结构。

## 声明与定义域

沿用普通 E 的 `id/kind/at/target/field/cond`，增加来自有限调用族格式的 `indices` 与 `order`。以下字段是一个示意声明。完整文档还包括给出 `history[i]` 的 T 定义及正常和异常出口。

```yaml
id: $e_2
kind: state
at: entry
field: visible
target: value.at_or($e_1, iteration1.index, null)
cond: '!value.field(value.at_or(value.field($t_0, "history"), iteration1.index, value.record("count", 0, "failed", false)), "failed") && value.at_or($e_1, iteration1.index, null) != null'
indices:
  - name: iteration1.index
    type: i64
    domain: 'CASE WHEN $e_0 == null THEN [] ELSE value.indices(value.length($e_1)) END'
order: [iteration1.index, 0]
```

`id` 沿用与普通 E、S 响应共享的裸 `$e_N` 编号。带索引的应用写成 `$e_2(iteration1.index)`。首批验收一个 i64 位置和一个非负词法序号，位置绑定属于特定 typed Vector 递推。domain 使用该递推输入的长度，T 未激活时由外层 CASE 返回空域。空域没有位置，因而不求值 cond 或 target。普通 E 的原格式保持有效。

每个域内位置在 cond 成立时才有已定义的应用。此时 target 必须是已认证可达的非空原堆引用，字段类型来自同一审查过的堆布局。例如，从已取得的原列表 items 向量取第 i 个引用，再读它的普通字段。相同入口堆、对象身份与字段在不同索引、不同别名路径或普通 E 中都指向同一个快照值。重复读的字段若保存引用，也保持原引用身份。前序写入已能转发时缩小 E 的取得域，当前读取值在纯表达式中由转发结果和入口快照共同决定。

## 历史前缀与取得顺序

沿用[有限循环状态历史](final-state-history-pers.md)的 `record<current:Q,history:vector<Q>>`。索引 i 的条件和 target 可读取 `history[i]` 与同位置更早取得的观察。T 当前步按已有惰性 CASE 取得当前应用，计算并提交 `history[i+1]`。提前返回或异常后纯扫描仅补吸收态，后续 E 和 S 都保持未发生。循环后如需继续读某一个已选择引用，先从 Q 投影该引用，再按既有普通 E 合同取字段。

条件与 target 只依赖当前元素和此前取得的观察时，可以使用普通纯 Vector Fold。此时以唯一实际引用该索引应用的 Fold 当前步，连同匹配的输入与激活域，确定作用域。需要早停、异常吸收或写入转发时，使用前述历史前缀。相同拼写的 binder 来自不同 T 时仍属不同作用域。cond 或 target 读取当前 T 出口、未来前缀、自己或同位置尚未取得的观察均无定义。与同步 S 组合时，仍须按同一前缀和站点次序证明观察已发生，响应引用还需证明处于正常非空域。

例如先读 `visible` 再按其结果读 `code`，前者只在尚未失败且该项非 null 时取得，后者再要求已经取得的 visible 为 true。空序列没有读取，null 元素失败且后续停止读取。两次访问同一对象时两个 visible 应用都必须满足同一入口快照。若算法先按引用身份去重，重复项不会扩大字段取得域。

## 两层有限索引

在外层逐项取得原对象的子列表时，`indices` 可声明两个不同的 i64 位置。第一个位置仍由外层 Fold 的有限输入与激活域决定。第二个位置的域只依赖该父位置已取得的子向量和此前观察，未进入子循环时为空。两个位置只描述取得域，同一原对象的同一入口字段仍共享快照值。

`order: [outer.index, phase, inner.index, site]` 先确定父位置和子阶段，再确定子位置和站点。父层仍用 `[outer.index, ordinal]`。父层提供子向量的站点必须早于子阶段。子表达式以当前父位置访问父 E，并以 `$e_N(outer.index, inner.index)` 应用当前子 E。外层通过子 T 的结果承接正常值与失败，不能直接借用子 E。

子 T 有显式父索引和原规则向量参数，由实际的外层当前步传入。子取得域只能引用该父实例已取得的向量。子步只读同一实例的当前 `H_inner(i)[j]`，本步结果提交到下一前缀。父前缀只接收当前实例的最终完成。内层失败使本轮后继与后续外层读取均不发生；空子向量无内层读取。参数化 T 的 `when: true` 约定保持有效，实际调用域由外层 CASE 保留。

该阶段的守卫核对完整父/子绑定、先声明的子 T、唯一词法站点、当前索引元组和已取得的父向量来源。它拒绝未来前缀、交换或偏移索引、借用同名的另一 Fold、跨父实例，以及内层定义域依赖自身或晚站点。这一历史分支只接收由更早的父 E 提供的原 Vector。


若完整的源计算已经产出有限 record 向量，正常出口可以另以纯父/子 Fold 投影其中仍指向原堆的字段。父输入及激活域取已完成的定义。父当前步传入自己的索引和当前 record 中的子向量字段，子参数保持显式索引与向量。子索引域是这一实参向量的长度。E 从其中当前子 record 的原引用字段取得入口快照，按父阶段与子位置排序。此分支使用唯一实际应用确定两个 Fold 的作用域，不额外构造历史。

守卫匹配父当前步的子向量实参与子索引域，核对当前父、子坐标，并拒绝依赖本次投影或后续定义的来源。纯投影没有自己的失败前缀，源遍历失败时父激活域为空，内容观察不会发生。若将来登记嵌套 UTF-16 投影见证，应保留完整的历史源递推，仅在正常域读取内容。

## 测试责任

静态守卫核对有限索引声明、关联的 Fold 结构、应用形状和作用域。该检查不能证明任意 cond 的域蕴含、任意 target 的堆类型、两个引用实际相等或数学方程正确。完整黄金的独立推导须检验前缀因果、可用性、null、首匹配或首异常、相同身份跨索引的快照一致性，以及所有边界发生事实。源码见证与黄金解释只提供辅助证据，正式验收仍直接比较生产 CLI 的完整 PERS 与唯一黄金。
