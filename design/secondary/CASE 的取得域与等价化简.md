# CASE 的取得域与等价化简

第八章及[完整二分 CASE 怎么选方向](完整二分%20CASE%20怎么选方向.md)决定优先级；本专题讨论可证明的化简和观察边界，而不是发明第二种选向规则。

## 宿主保护 CASE

关系来源的空值、非空与存在保护须来自同一已证明的来源和取得域。同名不证明来自同一批行。依赖取得域的部分 Boolean 不作为可以任意重排的 AND 或 OR 项。例如 `CASE WHEN source == null THEN false ELSE empty(source) END` 只在非空域检查集合是否为空。


对于业务 `number` 的二元取小值或取大值，两个返回臂必须恰好是参与比较的两个值，且已知它们可全序比较。相等时两者可互换，因此统一用严格比较。在证明是相同的极值运算后，使用共享比较键确定操作数方向，再按完整 CASE 规则定形。例如在 quota 的键在前时，较小值写成 `WHEN quota < total THEN quota ELSE total`，不另按结果臂长短或常量位置选向。这条规则只整理已经取得的业务值，调用次数、顺序和条件均保持原有语义。

相邻同值分支可按原顺序合并 guard：

```text
CASE WHEN C1 THEN V WHEN C2 THEN V ELSE W END
→ CASE WHEN C1 OR C2 THEN V ELSE W END
```

OR 左侧先求值；只有 `C1` 为 false 才求值 `C2`，与 CASE 只有在第一支未命中时才检查第二支相同。该规则只合并相邻同值分支，不跨中间不同结果分支直接合并原始 guard；只有各项已取得、总且可交换时，才统一 guard 内 OR 项的排序。已合并的 OR 必须作为一个 guard 保留，不能在二值 CASE 规范化时拆回重复结果分支。改写必须减少分支数，且再次归一保持同一结构。

非相邻同值分支仍使用首命中有效域 `D_i = C_i AND NOT(C_0) … AND NOT(C_{i-1})`，不能直接合并原始条件。显式 ELSE 且至少三种可达结果时，可合并同值有效域，非默认结果组保持首次出现顺序，原默认值仍在最后；只有分支数严格减少才应用。二值分区继续使用唯一二分规范，部分 CASE 不增加 ELSE。该方向不承诺任意等价多值分区已经具有全局唯一表示。

## 已取得的总布尔值

可交换、可结合且已取得的同族 AND 或 OR 展开后用共享结构键排序并固定左折叠，不能只检查叶子有序而保留不同树形。业务值采用 AND、OR 结构，不把宿主语法带进 R。若 `p`、`q` 都是已取得的总布尔值，`(p AND q) OR (p AND NOT(q))` 与 `(p OR q) AND (p OR NOT(q))` 都化为 `p`；换成另一个输入便不能抵消。受保护的部分观察不得套用。

## 正常结果守卫

返回 CASE 的 guard 可在已证明的正常完成域及首匹配分支域内删除冗余 AND 项。先认证全部叶子为该域内的纯总 Boolean，再展开、去重并按实际宿主 SortContext 的共享键排序；从大键到小键逐项证明“当前域 AND 当前其余项蕴含该项”，成立立即删除，最后按共享顺序左折叠。不能依据原始全体项批量删除，否则互相蕴含的两项可能同时丢失。首批认证限直接原生 Boolean 与已知入口原始值／引用的 null 比较，未知调用、字段、E／T 和部分 CASE 不参与。该规则只统一给定叶集合的删除方向，不宣称任意等价公式的全局最小形；也不规定异常域内 R 必须为 bottom。不得让后续处理破坏惰性边界。

对响应字段的扩展认证，必须沿已取得响应的真实端口 record 声明逐层查到字段类型，确认投影使用已登记且与声明绑定的字段投影，且返回类型与声明一致。只有这样的 Boolean 字段及已认证 nullable 原始字段比较可以参与上述 guard 归约；普通 pure Boolean 返型、同名函数、未取得响应、未知字段和任意 heap getter 都不构成证明。

## 不可变总运算的 CASE 外提

只在同一取得域内、直接参数的 CASE 完整且运算已证明为不可变、纯、总时，才考虑把 CASE 移至运算外。不能据 pure 标志推断总性，也不复制外部回执、观察、异常、标识分配或读取；保留参数次序、分支首匹配、类型及既有默认值。部分 CASE、惰性参数、未知调用和变更状态的操作不适用。

外提不是默认输出规则。若只是让整个值增加 CASE 臂或运算次数，保持内层 CASE；临时外提只能用于后续证明可严格降低整个表示复杂度的变形，最终按第八章比较整值。同复杂度不自动选择外提。若展开预算耗尽，报告未完成，不把半成品列为另一份可接受预期。
