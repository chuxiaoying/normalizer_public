# CASE 的取得域与等价化简

[《统一定形》的完整二分 CASE](../chapters/08-统一定形.md#cf-04-完整二分-case)决定优先级；本专题讨论可证明的化简和观察边界，而不是发明第二种选向规则。

## 宿主保护 CASE

关系来源的空值、非空与存在保护须来自同一已证明的来源和取得域。同名不证明来自同一批行。依赖取得域的部分 Boolean 不作为可以任意重排的 AND 或 OR 项。例如 `CASE WHEN source == null THEN false ELSE empty(source) END` 只在非空域检查集合是否为空。


对于业务 `number` 的二元取小值或取大值，两个返回臂必须恰好是参与比较的两个值，且已知它们可全序比较。相等时两者可互换，因此统一用严格比较。在证明是相同的极值运算后，使用共享比较键确定操作数方向，再按完整 CASE 规则定形。例如 `quota` 的键在前时，取小值的两个严格候选分别以 `quota < total` 和 `quota > total` 为守卫，相等处返回任一原值均等价。两者同成本，按共享运算符顺序选 `WHEN quota > total THEN total ELSE quota`，不为取小值另设方向。这条规则只整理已经取得的业务值，调用次数、顺序和条件均保持原有语义。

相邻同值分支可按原顺序合并 guard：

```text
CASE WHEN C1 THEN V WHEN C2 THEN V ELSE W END
→ CASE WHEN C1 OR C2 THEN V ELSE W END
```

OR 左侧先求值；只有 `C1` 为 false 才求值 `C2`，与 CASE 只有在第一支未命中时才检查第二支相同。这一步只合并相邻同值分支，不跨中间不同结果分支直接合并原始 guard。符合[纯布尔多臂 CASE](../chapters/08-统一定形.md#cf-11-纯布尔多臂-case-从有效域选形)的情形，先求首次实际命中的域，再合并，不合并原始 guard。只有各项已取得、总且可交换时，才统一 guard 内 OR 项的排序。已合并的 OR 必须作为一个 guard 保留，不能在二值 CASE 规范化时拆回重复结果分支。改写必须减少分支数，且再次归一保持同一结构。

非相邻同值分支先按首命中计算有效域 `D_i = C_i AND NOT(C_0) … AND NOT(C_{i-1})`，不能直接合并原始守卫。若合并后的候选能保留取得、正常和异常的有效域并严格减少复杂度，才进入《统一定形》的等价候选比较。原源码中哪组先出现，不是输出定形键；固定一种首次出现顺序不能证明等价变体收敛。部分 CASE 不增加 ELSE。

符合 [CF-11](../chapters/08-统一定形.md#cf-11-纯布尔多臂-case-从有效域选形) 的完整总布尔 CASE 从有效域生成整组候选，同成本的排列也比较整式，不把局部合并必须降成本的条件当成整式比较的条件。父域内若只能取 `a == b` 的赋值，分别翻转 a 或 b 不在有效域，不能因此删去这两个入参。

## 已取得的总布尔值

可交换、可结合且已取得的同族 AND 或 OR 展开后用共享结构键排序并固定左折叠，不能只检查叶子有序而保留不同树形。业务值采用 AND、OR 结构，不把宿主语法带进 R。若 `p`、`q` 都是已取得的总布尔值，`(p AND q) OR (p AND NOT(q))` 与 `(p OR q) AND (p OR NOT(q))` 都化为 `p`；换成另一个输入便不能抵消。受保护的部分观察不得套用。

## 正常结果守卫

在已证明的正常完成域和首命中有效域内，只有当其余条件足以蕴含某项，且移除该项不会跳过原有观察、异常或取得条件时，才可删掉它。每次删除后都需按剩余条件重做蕴含判断，不能把依赖彼此的条件同时删光。最终按《数学化简》《统一定形》比较化简后的整个值；固定删除顺序本身不能证明等价变体收敛。

对已取得响应的字段，证明须来源于该次回执及其真实类型声明。函数返回 Boolean、字段同名或打印出来相似，都不足以证明取得域和总性。

## 不可变总运算的 CASE 外提

只在同一取得域内、直接参数的 CASE 完整且运算已证明为不可变、纯、总时，才考虑把 CASE 移至运算外。不能据 pure 标志推断总性，也不复制外部回执、观察、异常、标识分配或读取；保留参数次序、分支首匹配、类型及既有默认值。部分 CASE、惰性参数、未知调用和变更状态的操作不适用。

外提不是默认输出规则。若只是让整个值增加 CASE 臂或运算次数，保持内层 CASE；临时外提只能用于后续证明可严格降低整个表示复杂度的变形，最终按《统一定形》比较整值。同复杂度不自动选择外提。若展开预算耗尽，报告未完成，不把半成品列为另一份可接受预期。


当精确整数的加法或乘法两端是同一个**已经取得且总有定义的完整二分 CASE**，可以只保留一次分支选择，在两臂中分别对该臂的值执行原运算。比如 `C * C`，其中 `C = CASE WHEN p THEN a ELSE b END`，化为 `CASE WHEN p THEN a * a ELSE b * b END`。两处 CASE 的守卫、值及取得域须相同；完整 CASE 从两份减为一份，条件臂从四条减为两条，优先级高于两臂各有一次乘法所增加的运算数。这是沿同一守卫同步取臂，不对两组不同 CASE 做交叉展开。缺少总性或不能严格降复杂度时，不套用这一步，也不为了共享先展开子树。
