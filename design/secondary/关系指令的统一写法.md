# 关系指令的统一写法

关系指令写在原语句所在的位置：`/* @normalizer-ir target = operation */`。每块只写一条指令，普通目标在同一作用域声明；在首次读取前必须确定已初始化。指令与原语句不能各运行一次。以下是第五章规定的受限语法，不是通用 SQL，也不是输出的 SQL 打印格式。

| 操作 | 写法 | 边界 |
| --- | --- | --- |
| 查询、投影和绑定 | `from source as r where predicate yield { amount: r.amount }`；`let name = expr` | 表来源、已取得行、字段类型和行内作用域明确；按支持的载体决定记录或标量投影。 |
| 筛选和次序 | `where predicate [and predicate …]`；`order by key [, key …]` | 不是通用 OR、任意排序方向或排序规则子句。不得从无序来源推一个稳定「第一条」。 |
| 计数、合计和分组 | `count [distinct] from source as r … [yield expr]`；`sum from source as r … yield expr`；`count groups from source as r by key [, key …]` | 保留重复、空集和列空值边界。分组计数限未筛选的已声明表和明确列。 |
| 联接与并集计数 | `count from left as a join right as b on predicate [where predicate]`；`count distinct union left.field, right.field [, …]` | 前者是已绑定表的内连接计数，后者至少两支，先投影指定列再并集去重；不承诺任意 JOIN 或并集。 |
| 首项与任选 | `first from rows as r … yield expr else fallback`；`first from values[k:] else fallback`；`choose from members else fallback` | 位置 k 是非负整数字面量，省略时为 0。任选在每个源码位置独立发生，不能冒充首项。 |
| 局部查键 | `m = value.map_empty(text, text?)`；`m = value.map_put(m, "key", value)`；`x = value.map_get_or(m, "key", fallback)` | 局部映射、文本字面量键、可空文本值。只有缺键才采用后备值，存在但值为 null 仍返回 null。 |
| 有序递推与整数区间 | `x = reduce values from initial as (acc, item) yield expr`；`n = count from [lo, hi) as i` | 保留初值、更新依赖和边界。只有 sum 和整数区间 count 可用 `+=`，且目标此前已初始化。 |
| 表写入 | `insert into`、`update … set … [where …]`、`delete from … where …`；完成子句 `returning affected_rows atomic throws ErrorType` | 保留实际目标、命中条件、行数、原子性和异常。DELETE 必须显式有条件；UPDATE 只有源合同本来允许时才不带条件。 |

查键示例：后备值是 `"备用"`，键缺失时返回它；键存在但对应值显式为 null 时返回 null。选择哪个值与源语言先求值什么是两回事。若源语言在调用前已求值后备实参，不能借查键规则取消或推迟其中的动作。

只对已取得的同一批数据做等价化简；一次写入之后重新读表是不同的观察。输出 SQL 可以使用相应输出合同定义的语法，这并不扩大分析源码可注入的语法。
