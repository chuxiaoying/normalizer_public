# 有序序列的长度与首项

本专题细化第五章的有序序列与关系运算。正常值的改写不能删除源语言异常，也不能改变顺序、重复项或观察取得的前提。

## 有序 Java 常量数组

对于已执行的封闭 Java `int[]`，初始化值按源顺序占据对应位置，不能应用标量 Add／Mul 的交换律移动元素。声明简写与显式初始化共享唯一语义；`new int[n]` 则先求长度、再得到长度为 `n` 的零填充数组，不能与 `new int[]{n}` 同形。读取可确定的长度和位置直接归约；在当前取得域越界或负长度时保留各自的真实异常及 guard，而不是正常返回 null、补零或把异常推到无关路径。该例的[设计种子](../examples/topics/unified-canonical-form/java-constant-array.md) 不把可变数组归为不可变 Vector，也不认证对象身份、写入、逃逸和符号长度。

## 已取得 typed Vector 长度的自然域

宿主可认证原生 `ValueLength` 的精确自然数域，但证据必须同时包含：接收值在当前宿主域已经取得；完整声明类型确为不可变 Vector；若来自响应或 record 字段，完整字段路径逐层有声明类型，且该取得条件已成立。字段中的 Java null 标志不使完整 record 的其他载荷变成未定义；相应源异常仍由独立 throws 保留。不能仅凭 `Ty::I64`、普通 Number 返型、函数名包含 length、相似打印或尚未取得的 E/T 推断这些前提。

通过认证的长度 subject 取值域为无有限上界的自然数，不按 i64 标签截断。单一 subject 的总比较沿整数区间规范在该自然域内计算真集与补集：长度 `> 0` 的真域是 `[1,+∞)`，补域是单点 `{0}`；单点统一用 `== 0`。对于“正长度返回 A、空长度返回 B”的完整二分值 CASE，若 A/B 均非 null、非嵌套 CASE，两种守卫计算并缩减到其在自然域内的真集后，空域分支恰为单点的等值守卫，定形为 `CASE WHEN length == 0 THEN B ELSE A END`。不能将等价但未定形的 `<= 0`、原源码 `> 0` 或正域 `>= 1` 同时作为可接受黄金。 对非单点下区间，例如长度至多 1 与长度至少 2，用同一断点表示为 `length <= 1` 与 `length > 1`，不分别打印两个不同的边界常量。两臂复杂度不变时，完整二分按第八章选择 `>` 的基准方向并同步交换结果臂。

独立 TypeScript 入口的证据形状是：入口声明非空 `ReadonlyArray<number>`，适配层交付有类型 Vector 后，内核才能使用已认证的长度观察。左右换位、空分支反写、阈值变化、可空 Vector 和普通业务数字都有全量断言。这里只解释声明中的长度，不把宿主稀疏数组的长度当作已存在索引的计数；响应或深层记录路径仍需独立验收。

这个规则只使用当前取得域内的 typed Vector 自然域证据，不扩展未知调用、未声明字段、nullable／部分接收值或任意 E 路径；它也不授权把 Source 的零项规则跨类型套给 Vector。源语言显式 word 转换与回绕仍独立保留，原标准 Java List 的有限可达上界不替代一般数学 Vector 的域定义。

## 保序序列第零项的统一规范

对顺序、元素类型和宿主取得域均有明确证据的纯序列关系，`NthValue(index=0, default=null)` 统一为同一关系的 `FIRST(identity projection, default=null)`。索引零必须是精确整数字面量；Base、Project、Select 等输入结构不构成保留另一种索引／SQL 表达风格的理由。带投影的关系须通过既有投影组合规则保留其实际元素值，不能改成底层未投影对象。

此规则保留顺序、重复元素和首项 null：`FIRST` 读取第一个元素，不附加非 null 过滤。可空投影具有非空缺省时，只有无记录才使用缺省。规范用存在性 CASE 保护首项；不能把选中记录的 null 当成空集。源语义如果已过滤 null，保留同一关系中的该过滤；不能把未过滤的第零项换成第一个非 null 元素。Java 的 null 接收者和空集合越界仍由独立 throws 域表达；`default=null` 只是纯选择值表达式的默认值，不授权删除源异常。

固定方向只从合格的第零项观察改为 FIRST，再执行既有关系／投影归约；不反向生成 Base 索引打印，不以原 IR 结构、入口或语言决定风格。不覆盖非零／未知索引、非 null fallback、缺少顺序证明的关系，也不移动 E、调用或迭代绑定。前提不满足时保留原观察。合同规定目标代表，生产归约及 renderer 仍须通过独立完整断言证明已统一，不能将等价索引打印作为第二份可接受预期。 对直接取得的有序标量数组，R 写成 `FIRST(value FROM values)`，只替换值观察，不改 S 中的索引写入目标，也不改越界的 throws。

[先完整投影后取首项](../examples/topics/collections/java-eager-first.md)的 FIRST 只表达正常完成时的值。先扫描整个非空记录数组，后行的空工单仍能使投影失败；取索引的越界条件在投影成功之后。仅当确证同一输入为空时，才移除对过滤子集再次判空的守卫，不从同名别名猜测相同关系。

[跨表投影去重](../examples/topics/relational-data/sql-projected-distinct.md)先用已声明的非空标量列构造每条投影，再对同类无序集合做并集。交换或重复分支不改变可能值；同一分支重复时仍按投影值而非整行去重。改变投影列则是另一种业务结果。

[显式空值覆盖缺省](../examples/topics/collections/java-map-present-null.md)将键的存在性和可空载荷作为不同事实归一化：只有缺键才取 fallback；已存在的 null 不是缺键。不能用 COALESCE 或普通非空测试替换此规则。

FIRST 的选中值若为 CASE，且同一行绑定的过滤域已蕴含某个显式分支的首匹配有效域，可用该分支的原行值或纯字面量替换选中 CASE。首批证明限 Base 与连续 Select、行值的 null 比较和总 Boolean 组合；未知调用、其他行绑定、技术观察根及未取得 E 不参与。原关系和空集默认值保留，后续既有规则可继续归约；部分 CASE 不补 ELSE，不跨投影绑定取用外层同名行，也不增加求值或改变身份。

## 两个保序快照的共同位置范围

当两个非空入口引用提供长度已取得的不可变记录序列时，`indices(LEAST(LENGTH(x), LENGTH(y)))` 枚举两序列都存在的位置，不包含上界。只在长度这两个纯、总、已经取得的自然数上使用 `LEAST` 的交换律，按共享结构键排序；同一快照的两个长度去重为单个长度。两个序列在实际位置表达式里的职责不交换：对关闭序列取 `i`，对打开序列取 `LENGTH(opened) - 1 - i`。任何一个输入可能为空，也不得访问界外位置或去掉重复编号。见[打开与关闭的反向位置对照](../examples/topics/state-and-aliasing/java-lifo-release.md)。
