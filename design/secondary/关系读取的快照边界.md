# 关系读取的快照边界

本专题细化第五章的关系取得和第七章的 PERS。表声明说明物理来源和列合同，不保证每次查询取得相同的行。

- 对已取得的行绑定重新计数，不是重读。一次可能成功的同表写入之后再次物理读表时，新的行属于独立的环境观察；不能用旧行、表名或相同 SQL 替代。
- 保留实际读取条件和它与已发生且成功的同表写入之间的依赖。每条依赖指向真实写入完成，只在该完成可达时成立。分支汇合后实际读取一次，就只记录一次观察；不能为没发生的写入捏造回执。物理读取本身不新增写动作。
- 除非有隔离与无并发的合同证明，不能用写入影响行数替换两次快照的行数差。两次快照恰好等值，也不证明它们是同一次观察。

判别例：同账户原有一行，删除成功且期间没有其他修改。重读时，前后行数之差为 1；复用删除前已取得的行时，差为 0。若删除失败且未被捕获，仍保留写入尝试及失败回执，但没有第二次读取。机器字段见 [PERS 接口](../../implementation/contracts/business-pers.md)。
