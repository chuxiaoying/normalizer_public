# 十个容易看错的业务边界

每个例子给出一组只差一点的输入或源码。先判断返回值、写入、调用或异常会怎样变化，再与案例中的理想结果对照。

| 案例 | 试着换一个条件 |
|---|---|
| [从另一个引用读回额度](java-state-alias.md) | 两个对象起初都是 3。只给其中一个写 7，然后分别通过同一引用、另一对象和空引用读取。 |
| [默认标题与显式空值](java-map-present-null.md) | 默认标题是“应付”。没有设置标题时用默认值，显式清除标题时应返回什么？ |
| [读取整组票号后返回首项](java-eager-first.md) | 第一张票的编号是 21。添上一行空票后，还能正常返回 21 吗？ |
| [逆序关闭任务](java-lifo-release.md) | 按 1、2 打开，分别按 2、1 和 1、2 关闭。数量相同，结果相同吗？ |
| [回执的可选槽与追踪码](typescript-tuple-slots.md) | 成功时第一个位置是 `undefined`。它占不占位，会怎样影响尾部两条追踪码的计数？ |
| [业务流水号回卷](java-explicit-rollover.md) | 源码写明“达到上限就回到起点”。删掉这个显式分支，加一的业务公式还会回卷吗？ |
| [登记回调与真正派发](frontend-deferred-listener.md) | 一次只登记，另一次登记后再派发。各会产生几次外部调用？ |
| [两次独立选择报价](java-independent-choice.md) | A 报 7、B 报 9。两次选择可以来自不同报价；第一次选择的编码和价格能否来自两份报价？ |
| [跨两批账单统计不同账户](sql-projected-distinct.md) | 账单 101 和 202 都属于账户 7。把第二张的账户改成 8 前后，分别应数出几个账户？ |
| [合法入口旁的非法方法名](java-invalid-declaration.md) | 同文件中未调用的方法名叫 `return`，改名为 `booleanValue` 前后，入口分别能否生成 PERS？ |
