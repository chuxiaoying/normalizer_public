# 统一正则规范专题

[统一正则规范](../../../unified-canonical-form.md)是设计源头。此主题只测试「不同写法是否得到同一个唯一结构」和「不该合并的语义是否保持不同」，不重复其他主题对业务运算本身的验收。一个规则可以复用其他主题已有例子；只有例子的实际完整断言验证了这条规则，才计入覆盖。

| 规则族 | 必须有的成对例子 | 对照反例或限制 | 种子与正式验收 |
|---|---|---|---|
| 精确整数 Add／Mul | 同一组符号的排列、不同括号、重复项与常量；固定左折叠，重复归约不变 | 文本拼接、浮点、word 运算、未取得值 | [加法种子](java-associative-normal-form.md)已有正向入口；乘法、非交换边界和跨入口还要逐项核对 |
| 总 Boolean AND／OR 与有序比较 | 交换两端且同步翻转符号；布尔排列和不同括号汇合 | 短路、可空和 NaN 不推出额外互补 | 关联[布尔代数](../expression-simplification/java-boolean-algebra.md)；专项成对覆盖待核对 |
| 完整二分 CASE | 正反条件与交换两臂得到同一代表；数值指示器、普通计数、min／max、Vector 各按其域 | 只取反不换臂、互换嵌套 CASE、部分 CASE 不补 ELSE、nullable 保留惰性 | [二分 CASE 种子](java-binary-case.md)起步覆盖计数；其他域须逐项验收 |
| 多分支 CASE、区间和 LET | 相邻同值合并、非相邻同值按有效域汇聚、区间交并补、合法提取和归约不动点 | 有重叠 guard 的首命中不能重排；禁止无 CASE 或仅出现一次的 LET | 关联[分支种子](../../series-1/java-static-case-when.md)；专项逐项补齐 |
| 纯总不可变构造与序列观察 | 总 CASE 外提的唯一方向、零索引统一为 FIRST | 不跨惰性／部分域；保留首项 null、顺序和越界异常 | 关联[集合主题](../collections/README.md)；专项逐项补齐 |
| Heap、E／T 业务名字与稳定编号 | 两次分配顺序不同但公开路径相同；纯定义别名和依赖图编号稳定 | 同名不合并不同对象或调用；禁止 S 乱序、移动取得域或重编号后漏改引用 | 待补专题种子与正式用例 |
| 顶层异常和边界结构 | 已证明互斥的异常记录独立排序；同内容完整结构严格相等 | 不交换具因果关系的异常或 S，不能丢载荷、cond 或取得条件 | 待补专题种子或关联用例核证 |

每一行验收都须列出实际种子 ID 与正式 CLI 入口，至少用同一份独立规范预期分别验证两种输入，并保留反例。不能用「比较两份 actual 彼此相同」代替黄金；有限域语义证明和幂等性检查是额外证据。待补不等于已通过。
