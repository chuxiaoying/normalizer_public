# 文本连接不交换：按顺序组成业务标签

## 设计意图

检验文本常量和转义先解释，连接保持原位置。移动前后缀可改变文本；字符字面量进入数值运算时遵循该类型，而不是强行按文本连接。

右侧文本足以让 `null + "s"` 成为文本连接，得到 "nulls"，不把字符次序颠倒。编译有效但未调用的辅助方法（如把布尔与整数装箱成 Object）不产生任何所选入口的执行结果；这不表示这种结果已支持直接投影。

## 输入原始代码

标签按「类别、编号」组成。连接运算符虽然也写为 `+`，但不是精确整数加法。

```java
class CanonicalLabel {
    static String label() {
        return "zone-" + "42";
    }
}
```

## AI 预处理结果

**原样通过。** 两段都是原生文本常量。AI 不交换，不替内核折叠。

## 归一化最终结果

```yaml
schema: normalizer.pers/1
entry: { function: src/CanonicalLabel.java#CanonicalLabel.label, returns: text }
P: { parameters: {} }
R: '"zone-42"'
```

跳过排序不等于跳过常量执行。按源码顺序得到 `zone-42`；主动交换输入则得到 `42zone-`，不能复用同一份预期 PERS。两段分别连接空串不改变原结果。

## 字符常量先还原，才执行确切整数运算

```java
class CanonicalLabel {
    static int charCode() {
        return '\141' + '\n';
    }
}
```

**原样通过。** Java 的八进制转义 `\141` 是 UTF-16 单码元 97，换行是 10；相加是整数 107，而不是把源码的反斜线按文本拼接。用同一码元的普通字符替换转义，结果不变。

```yaml
schema: normalizer.pers/1
entry: { function: src/CanonicalLabel.java#CanonicalLabel.charCode, returns: number }
P: { parameters: {} }
R: '107'
```

### 字面量内部的转义与边界

源码入口先识别完整的 Java 字面量，再提交已经解释的值给内核。整数例 `charCode` 保持右侧换行（10）不变；左侧按 Java 的规则变更。转义长度不能吞掉下一个字符。

| 左侧写法 | 单码元 | 整数结果 |
|---|---:|---:|
| `'\b'`、`'\f'`、`'\r'`、`'\t'` | 8、12、13、9 | 18、22、23、19 |
| `'\''`、`'\\'`、`'\s'` | 39、92、32 | 49、102、42 |
| 八进制 `'\7'`、`'\77'`、`'\377'` | 7、63、255 | 17、73、265 |

字符只允许一个 UTF-16 码元。八进制首位大于 3 时至多读两位，因此 `'\477'` 留下额外一位，不能当作单个字符。空字符、无效转义 `'\q'` 和未转义的物理换行都是源码错误，入口拒绝，不进入模拟或生成 PERS。这里验收字面量内部的转义；Java 的源码级 Unicode 转义由入口在分词前解释，见[源码词法合同](../../../../implementation/contracts/normalized-source-contract.md)，不是这一层的字符串转义，也不交给 AI。

### 源码级 Unicode 转义不是预处理任务

按 [JLS §3.3](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.3)，入口先翻译有效的 Unicode 转义，再识别注释、字符和字符串。合法转义不改变同一个字符的业务值，也不改变注解身份。第二个连续的原始反斜杠不必启动转义；一组高低代理项可拼成补充字符。若转义先产生换行，行注释就应在此结束；若换行落在字符字面量里，则源码不合法。合格的 Unicode 转义起始符后缺合法十六进制数字，即使位于注释也不可以忽略。

Java 字符常量承载一个 unsigned UTF-16 码元，不要求这个码元本身是 Unicode 标量。`\uD800` 作为单个 char 参与精确整数运算时值为 55296，本种子加换行 10 后得到 55306；作为 Unicode 标量文本输出是另一个边界，不能悄悄换成替代字符。它在注释中不影响语义。
