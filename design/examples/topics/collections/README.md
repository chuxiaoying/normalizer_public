# 集合

本主题研究 Java Collection、JavaScript Array、TypeScript Tuple 等集合的筛选、映射、聚合、首项、去重、顺序、空值和槽位语义。集合操作可以持续形成从单元素读取到多操作组合的难度梯度。

代表种子：[筛选后统计正数](java-filter.md)、[先完整取号再返回第一项](java-eager-first.md)、[显式空值覆盖默认标题](java-map-present-null.md)、[回执的可选槽](typescript-tuple-slots.md)、[两次独立选择报价](java-independent-choice.md)。
